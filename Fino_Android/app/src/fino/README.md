Put this client's own assets in `res/drawable/` (same filenames — they override the ones in main/):

  res/drawable/ic_brand_mark.xml            splash / loading-overlay logo
  res/drawable/ic_launcher_foreground.xml   launcher icon foreground

In Android Studio, right-click res > New > Image Asset generates both.
Note: only .xml and .png files are allowed anywhere under res/.
